# License texts

The following files are verbatim license texts from SPDX License List Data v3.29.0,
commit `31ba1a50e5397e00a304dbadc76531740e89ee48`:

- `Apache-2.0.txt`
- `GPL-2.0-only.txt`
- `GPL-3.0-only.txt`
- `LGPL-2.1-only.txt`
- `LGPL-3.0-only.txt`
- `BlueOak-1.0.0.txt`

Source: https://github.com/spdx/license-list-data/tree/31ba1a50e5397e00a304dbadc76531740e89ee48/text

Line endings are LF, with a single final newline. The original license texts,
including their publishers' copyright notices and example appendices, are kept
intact. Felt writes these documents without adding source headers or project notices.

The `-only` and `-or-later` variants use the same license document. The project's
SPDX notice in each source file selects the variant. SPDX's LGPL 3.0 document already includes the
complete GPL 3.0 text; Felt retains both parts without appending another copy.

`MIT.txt` is the MIT license text with `${year}` and `${author}` placeholders for
the project's copyright notice.

These documents are licensing templates, not a change to Felt's own Blue Oak license.
